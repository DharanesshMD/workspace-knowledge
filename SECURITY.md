# Security reporting

Do not include secrets, personal transcripts, production database dumps or real customer data in public issues. For sensitive findings use the repository's GitHub **Security → Report a vulnerability** private reporting channel when enabled. If unavailable, request a private reporting channel without disclosing exploit details in the public issue. No monitored security email or response SLA has been established yet.

Provide affected revision, a synthetic minimal reproduction, impact and relevant platform versions. This project is pre-release; production security certification and penetration testing are pending. See [threat model](docs/security/threat-model.md) and [restore boundaries](docs/operations/restore.md).
