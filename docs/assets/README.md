# Repository brand assets

- [Cover](workspace-knowledge-cover.png): wide README header and repository thumbnail artwork.
- [Avatar](workspace-knowledge-avatar.png): square profile artwork using the same connected W mark.

Generated with the built-in image-generation tool. The avatar uses the cover as its identity reference. These are brand graphics; the application screenshots elsewhere in the README remain separate acceptance artifacts. These files do not change the application UI or upload repository/profile settings.

## Cover prompt

```text
Use case: logo-brand. Create a polished branded repository cover / social thumbnail for the open-source developer tool Workspace Knowledge. ONE finished wide image, approximately 2:1 landscape, designed for a GitHub README header and repository social preview. This app preserves reviewed reasons behind code and connects teammates with confirmed contributors; it is not a chatbot. Visual direction: precise editorial technology identity, deep midnight navy background, warm ivory typography, restrained mint accent. Elegant custom geometric W symbol made of three connected ribbon-like branches, with tiny squared connection points; convey connected code provenance, clear silhouette and ample empty space. Place the standalone mark at left, project name in large crisp typography to its right, with one smaller tagline below. Exact visible text only: "Workspace Knowledge" and "Know why the code exists before you change it." Both must be spelled accurately and read clearly at thumbnail size. Keep the main mark and all copy comfortably inside central safe margins. Sophisticated flat graphic artwork, highly legible, consistent stroke language, subtle navy-on-navy branching lines in distant background only. No UI screenshot, no mockup devices, no robots, no brains, no excessive circuit-board detail, no neon glow, no 3D, no fake badges, no extra words, no watermark. Single composition, not a collage or brand board.
```
