# v0.1 release gates

The source-only `v0.1.0-alpha.3` prerelease was published on 2026-10-17 while the repository was private. It points to `5b982a5`; current `main` has advanced and must not be described as that tag. The prerelease is not production-supported. Current release status is in the [production readiness ledger](production-readiness.md).

The intended first production-support boundary is a Linux Docker server with macOS developer machines. Advertise only exact architectures, client versions and surfaces with matching install, workflow and failure-mode evidence. Other platforms/adapters remain experimental or partial. Automatic publication remains disabled and ordinary API/MCP retrieval stays advisory.

## Production release checklist

- [ ] Select and validate the production OIDC provider with separate portal/collector audiences, PKCE, expiry/rotation and HTTPS proxy behavior.
- [ ] Pass the expanded synthetic privacy corpus and publish an exact client/version/surface support matrix; ambiguous or partial input remains held/private.
- [ ] Complete signed/notarized macOS distribution, clean installation/update/uninstall, dependency notices and exact rollback.
- [ ] Complete a consented real-team pilot and long-duration target-server/capacity profile; publish measured limits rather than extrapolations.
- [ ] Complete independent security review and disposition findings; verify the actual vulnerability-reporting channel.
- [ ] Pass complete local checks, dependency/history/secret scans, container and exact-head GitHub CI. The current GitHub run at `5605d78` did not start because account billing/spending-limit blocked runners; resolve and rerun.
- [ ] Refresh retained Actions run-log and artifact inventory, historical disclosure review, and license/notice inventory after final CI. Do not delete remote evidence without explicit authorization.
- [ ] Reproduce clean install through the first supported team workflow and reconcile README, SECURITY, changelog, install docs and release notes.
- [ ] Owner reviews evidence and manually changes repository visibility. No agent changes repository visibility.

These are release gates, not claims that the application is currently production-ready. Owner resources or decisions are needed for provider selection, Apple signing, pilot infrastructure/participants, reviewer scope and GitHub billing. No paid resource, external account or real-team data use is inferred by this checklist.
