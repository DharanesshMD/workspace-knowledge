# Knowledge workbench

Use a quiet engineering notebook: persistent navy navigation, broad search column and a readable evidence inspector. The characteristic element is a service-scope rail accompanying every result, making shared ownership visible without exposing conversations.

Palette: paper #f5f7fb, ink #172c48, navigation #19375a, action blue #185fba, caution #805600, boundary #cbd5e1. System humanist sans (`Segoe UI`, `Helvetica Neue`, sans-serif), 15px text, 32px view titles; code identifiers only in monospace. Left align content, 70-character prose measure. No decorative graphs or metrics.

Desktop: navigation | search/results | selected knowledge. Mobile: navigation wraps above results; detail follows as an accessible region. Review actions identify the current revision; conflicts retain edits. Graph is a semantic relationship list with keyboard-accessible links, never a fabricated network. Status and environment schemas are read from authenticated endpoints or shown explicitly unavailable.

Review against brief: a generic dashboard of statistic cards would conceal uncertainty and service permissions. This design instead emphasizes provenance, scope, visibility, missing coverage and deliberate publication. Every displayed record is server-provided. Tokens remain in memory. No external fonts, analytics or image services.
